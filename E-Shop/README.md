
# E-Shop Project

Welcome to the E-Shop project! This is a simple and modern e-commerce website designed for showcasing products and providing an interactive shopping experience. It allows users to browse products, add them to their cart, and proceed with checkout. 

## Live Link
https://mdparvez-alam.github.io/browser_programming_assignment/E-Shop/eshop.html

## Features

- **Responsive Design:** Ensures the site looks great on both desktop and mobile devices.
- **Product Catalog:** Displays a list of products retrieved from a JSON file.
- **Shopping Cart:** Allows users to add products to their cart and view the total cost.
- **Simple and Clean UI:** Easy-to-navigate interface.

## Technologies Used

- **HTML**: Structure of the website.
- **CSS**: Styling and making the website responsive.
- **JavaScript**: Functionality for interactive elements like the shopping cart.
- **JSON**: Storage of product data.
- **Logo**: Custom logo used in the header.



## File Structure

- `eshop.html`: The main HTML page for the website.
- `style.css`: Contains the CSS styles for the website.
- `script.js`: JavaScript for handling interactions such as adding products to the cart.
- `products.json`: JSON file that holds the product data (name, price, description).
- `logo.png`: Image used for the website's logo.
