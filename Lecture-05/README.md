# MD PARVEZ ALAM — Portfolio (Lecture 05)

Personal portfolio built for the Web Fundamentals course at Savonia University of Applied Sciences.

## Features added in Lecture 05

| Feature | How it works |
|---|---|
| **Skills section** | 8 skill cards in a responsive CSS grid |
| **Projects section** | 3 project cards with title, description and GitHub link |
| **Theme toggle** | `isDark` state variable + `body.classList.toggle('dark')` |
| **Persistent theme** | Saved/read with `localStorage` key `portfolio_theme` |
| **Last updated date** | Generated by JavaScript on every page load |
